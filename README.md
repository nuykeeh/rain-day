# R.A.I.N. DAY

불타는 우주 쓰레기가 쏟아지는 날, 우주청소팀 대원 1~3명이 **한 화면에서** 쓰레기를 잡아 수거선에 넣는다.
지구는 다 같이 지켜야 하지만, 점수는 혼자 챙기고 싶다. 한 판 90초.

전시용 파티 게임. 바닐라 JavaScript + Canvas 2D + Vite. 외부 엔진·CDN·서버 없음.
명세는 [`PRD.md`](./PRD.md).

> **현재 M1 + v3.1 패치까지 구현됨.**
> v3.1에서 박치기 입력을 더블탭으로 바꾸고, 캐릭터 특수능력·대형 위성·보급품·라이벌 기절·R.A.I.N. 러시를
> M2에서 앞당겨 넣었으며 난이도를 올렸다. 게임패드·관리자 오버레이는 아직 M3 범위다.
> 다음 단계는 **사람 3명의 플레이테스트**다 (PRD 9절 관문 1).

---

## 실행

```bash
npm install
npm run fonts     # 한글 폰트를 public/fonts/ 로 복사 (최초 1회)
npm run dev       # http://127.0.0.1:5173
```

전시장:

```bash
npm run build
npm run preview   # http://127.0.0.1:4173
open -a "Google Chrome" --args --kiosk http://127.0.0.1:4173
```

- **Chrome이 이미 켜져 있으면 `--kiosk` 가 무시된다.** 완전히 종료한 뒤 실행할 것.
- `file://` 로 직접 열지 않는다. 반드시 로컬 서버.

## 조작 (플레이어당 버튼 3개)

| 자리 | 캐릭터 | L | M | R |
|---|---|---|---|---|
| 1P | 토끼 | `Z` | `X` | `C` |
| 2P | 개구리 | `V` | `B` | `N` |
| 3P | 원숭이 | `,` | `.` | `/` |

| 입력 | 동작 |
|---|---|
| L / R 누르고 있기 | 좌우 이동 |
| M | **잡기.** 수거선 바로 아래에서는 **배낭 전부를 던져 넣기** |
| **L 두 번 빠르게 / R 두 번 빠르게** | **그 방향으로 박치기.** 맞은 대원은 쓰레기 1개를 흘리고 비틀거린다 |
| **M 길게 (0.4초)** | **캐릭터 특수능력** |

### 캐릭터 차이

| | 잡기 범위 | 잡기 쿨다운 | 특수능력 (M 길게) | 능력 쿨다운 |
|---|---|---|---|---|
| **토끼** | 130×130 (**가장 좁다**) | 0.36초 | **그물 설치** — 머리 위 4초짜리 그물이 닿는 쓰레기를 자동으로 담는다 | 7초 |
| **개구리** | 300×80 (가로로 김) | 0.50초 (**가장 느림**) | **혀로 훔치기** — 바라보는 쪽 대원의 배낭에서 1개를 뺏어 온다 | 5초 |
| **원숭이** | 80×300 (세로로 김) | 0.24초 (**가장 빠름**) | **꼬리 채찍** — 아주 멀리 위쪽 쓰레기 1개를 즉시 낚아챈다 | 2.5초 |

> 모양만 다르면 원형이 제일 무난해지므로 **면적과 쿨다운으로 대가를 치른다.**
> 토끼는 범위가 제일 좁은 대신 그물로 벌충하고, 개구리는 넓지만 느리고, 원숭이는 일찍 가로채지만 좁다.

### 규칙

- 배낭은 5칸. **한 번에 많이 넣을수록 점수가 뛴다**: 1개=1점 / 2개=3점 / 3개=5점 / 4개=8점 / 5개=12점
- 배낭 1칸당 **8% 느려진다.** 많이 들수록 박치기에 당하기 쉽다
- **개구리 ↔ 원숭이는 라이벌.** 둘이 박치기로 부딪히면 **둘 다 1.2초 기절**하고 전용 대사가 뜬다

| 쓰레기 | 지구 피해 | 특징 |
|---|---|---|
| 고철 조각 | -3 | 기본 |
| 불타는 운석 🔥 | -8 | 빠르다. 배낭 2칸, 점수 2배 |
| **대형 위성** | -20 | 느리다. **0.3초 안에 두 명 이상이 같이 잡아야** 잡힌다. 점수는 나눠 갖는다 (2인 이상에서만 등장) |
| **O.B.의 보급품** 📦 | 0 | 잡으면 5초 버프 — **자석**(잡기 범위 2배) 또는 **부스터**(속도 2배·무게 무시) |

- 낙하 간격은 1.0초 → 0.28초로 점점 짧아지고, **운석 비율도 20% → 45%로 오른다**
- 마지막 20초는 **R.A.I.N. 러시** — 배경이 붉어지고 간격이 0.6배로 줄어든다
- 지구 게이지가 **0이 되면 전원 패배**

## 튜닝 패널 — `F3`

코드를 열지 않고 재미를 조정하는 용도다. (PRD 8.2)

- 낙하 간격·속도·등장 비율·피해량 / 이동속도·배낭·감속 / 잡기 범위·쿨다운 / 박치기 / 수거선·점수표 / 한 판 시간
- 바꾼 값은 **이 브라우저에 저장**되어 새로고침해도 유지된다
- **"JSON 복사"** 로 바뀐 값만 클립보드에 담긴다 → 확정되면 그 JSON을 넘겨주면 `src/config.js` 에 반영한다
- **"기본값 복원"** 으로 되돌린다
- `?tune=1` 로 처음부터 열어둘 수도 있다

> 플레이테스트 중에는 튜닝 패널을 켜 두고, 판마다 값을 바꿔가며 "한 판 더"가 나오는 지점을 찾는 게 목적이다.

## 기타 키 / URL

| 키 | 동작 |
|---|---|
| `F2` | 즉시 대기화면 |
| `F3` | 튜닝 패널 |

| 파라미터 | 뜻 |
|---|---|
| `?autotest=1` | 가짜 대원이 자동으로 한 판을 진행 (테스트용) |
| `?speed=4` | 모든 타이머 배속 |
| `?seed=123` | 낙하 패턴 고정 |
| `?players=2` | autotest 인원 |
| `?idle=2` | 무입력 복귀 시간(초) |
| `?tune=1` | 튜닝 패널을 열고 시작 |

30초 동안 아무 입력이 없으면 자동으로 대기화면으로 돌아간다.
루프에서 예외가 나면 콘솔에 기록하고 대기화면으로 복귀한다 — 멈춘 화면으로 두지 않는다.

## 테스트

```bash
npm test
```

- `?autotest=1` 로 1·2·3인 한 판을 끝까지 돌리고 **콘솔 에러 0**을 확인한다
- 승리(90초 생존)·패배(지구 게이지 0) 두 경로를 모두 검증한다
- 배낭 감속, 넣기 점수 계산(2개=3점), 박치기로 쓰레기를 흘리는 것까지 수치로 확인한다
- **v3.1 메커니즘**(`tests/mechanics.spec.js`): 더블탭 방향 돌진, 특수능력 3종, 대형 위성 동시잡기,
  보급품 버프, 라이벌 기절·대사, 잡기 범위 밸런스 회귀까지 검증
- 실제 키보드 입력(`event.code`), 무입력 복귀, 튜닝 패널 저장, 누적 카운터도 자동 검증
- 화면 스크린샷은 `tests/screenshots/` 에 저장된다

## 아트 교체 (M4)

코드를 고치지 않고 데이터만 바꾼다.

1. 이미지를 `public/img/` 에 넣는다
2. `src/data/characters.js` 의 `name` · `color` · `image`(예: `'img/rabbit.png'`) · `lines` 를 채운다
3. `src/data/theme.js` 의 `junkKinds[].image` · `shipImage` · `prologuePanels` · `background` 를 채운다

이미지가 없거나 로드에 실패하면 자동으로 플레이스홀더(색 원 + 배낭 + 눈)로 그린다.
